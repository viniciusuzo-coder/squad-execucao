# Squad de Execução

Central que conduz e finaliza os projetos em curso sem looping.

- **Piloto:** o chat ou sessão de cada projeto, onde Vinicius decide.
- **Copiloto:** a central que acorda 1x por dia, executa o que está liberado e escreve o resumo do dia.
- **Diário de bordo:** o canal entre os dois, em `projetos/<nome>/DIARIO-DE-BORDO.md`.

Comece por `SKILL.md` e `kit-universal/`. Resumos diários ficam em `resumo/`.
